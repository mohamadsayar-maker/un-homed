# Un-Homed Interactive Prototype

An interactive point-cloud experience originally titled **Memory of Places**.

Upload images and optional audio into memory slots, then use body movement,
gestures, microphone volume, or manual controls to dissolve and distort the
scene.

## Controls

- `1`–`9` and `0`: switch memory slots
- `*`: hide or show the interface
- `F`: enter fullscreen

Camera and microphone features require browser permission and a secure HTTPS
origin. GitHub Pages provides HTTPS.
